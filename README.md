# DAAPAAK Cognitive Games

Cognitive games to keep your brain and mind active.

## Description

A collection of five cognitive mini-games for older adults. Each game targets different skills like memory, attention, and processing speed. It is designed to feel fun and easy. Automatically tracks performance to reveal cognitive trends over time. Provides clinicians with clear insights into patient cognition.


## Features

* **Recall Trail**:
* **Connect the Dots**: To play, simply click on a colored dot and drag a path through the empty tiles to the other dot of the same tile. The path must not go through other dots or other paths, and must be made of orthogonal line segments (no diagonals). Once all colored dots are connected, you win the game, and you can customize the difficulty in the menu near the top.
* **Reaction Time Test**: One you press start it will flash a change in the image to you and you must clothes screen. It adds each round i a trial and averages out the trials over a period set by the user. It has many varying levels of difficulty which are all increasingly challenging.
* **What is missing?**: Once you start, memorize the initial screen before the timer runs out. At the end of the timer, the scene will go black, and then come back with the same scene but one item missing. Guess which item disappeared.
* **Sudoku**: Once you press start, you have the option to choose between 3 difficulty levels and the timer starts running. While you play, when you see a red box, it means that you have placed the wrong number. When you finish, it shows you how long it took and how many mistakes you made.
